# Ubuntu Voice V1
## Problem: People who naturally speak Shona should be able to interact with AI comfortably.
## Goal: Press one button. Speak. Receive a helpful answer.
## MVP Features: Voice input,Text input,Shona support,English support,Voice response,Conversation history,Feedback button
## Things We Will Not Build Yet: Payments,Farming advice,Healthcare diagnosis,Government services,Multiple countries,Offline mode
## First Success: A user completes one conversation entirely in Shona.
